Lichess Arrow Colors

Lichess draws only the first move of each line. This draws the moves after it too, in the same green, fading as the line goes on. Slide to zero to turn it off.

Lichess draws weaker moves thinner. Colour already shows that, so all arrows are drawn the same size.

Changes apply immediately on open lichess tabs. Threat-mode and hand-drawn arrows are left untouched.
